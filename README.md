# Neon Pong Battle

Мультиплеерная неоновая аркада на выбывание для 2–6 игроков.

Поле — правильный многоугольник (N-угольник по числу игроков) со срезанными
углами (фасками), чтобы мяч не застревал. Каждая грань — «ворота» одного игрока.
Игрок двигает ракетку вдоль своей грани и отбивает мяч. Пропустил гол — потерял
жизнь; кончились жизни — вылетел, его сектор закрывается стеной.

## Архитектура

| Слой | Технология | Где |
|------|------------|-----|
| Сервер (API + физика) | Go, Gin, Gorilla WebSocket | `backend/` |
| Клиент | TypeScript, Canvas 2D, WebSocket | `frontend/` |
| Раздача статики и прокси | nginx | `nginx.conf` |
| Деплой | Docker / docker-compose | `Dockerfile` (в `backend/`), `docker-compose.yml` |

**Сеть:** серверный тик 60 Гц, снапшоты клиентам — 64 Гц. Мяч и ракетки других
игроков рендерятся через интерполяцию снапшотов с адаптивной задержкой
(по пингу); локально предсказывается только своя ракетка (Client-Side
Prediction с реконсиляцией по номеру ввода).

## Быстрый старт (локально, без Docker)

Нужен Go 1.22+.

```bash
# 1. Собрать фронтенд (нужен Node) — либо уже готовый dist/main.js
cd frontend
npm install
npm run bundle          # esbuild -> dist/main.js

# 2. Запустить сервер с раздачей статики
cd ../backend
$env:STATIC_DIR="../frontend"   # Windows PowerShell
export STATIC_DIR=../frontend   # Linux/macOS
go run .
```

Откройте `http://localhost:8080`.

> Если фронтенд уже собран (`frontend/dist/main.js`), этап 1 можно пропустить.

## Запуск через Docker Compose

```bash
docker compose up --build
```

Откройте `http://<IP-сервера>/`. nginx отдаёт статику и проксирует `/ws`,
`/create-room`, `/rooms` в Go-бэкенд.

## Как играть

1. Нажмите **«Создать комнату»**, настройте:
   - число игроков (2–6),
   - количество жизней (1–5),
   - ускорение мяча (вкл/выкл, +5% каждые 10 сек),
   - интервал появления новых мячей (0 = выкл, 10–30 сек, до 3 мячей).
2. Скопируйте ссылку или ID комнаты и отправьте друзьям.
3. Когда все на месте, создатель жмёт **«Начать игру»** — игра не стартует
   автоматически при заполнении комнаты, запуск только за создателем.
4. Управление: **←/→** или **A/D** — ракетка всегда движется вдоль вашей грани,
   которая после поворота камеры оказывается внизу экрана.
5. HUD сверху показывает жизни игроков и время матча. Выбывший игрок
   становится наблюдателем, а поле перестраивается под оставшихся игроков
   (N-угольник по числу выживших).

### Предметы (опционально)

При создании комнаты или в настройках реванша (экран после матча) можно
включить/выключить предметы. Если включены, игрокам в случайный момент выпадает
случайный предмет — слот справа от поля показывает, что у вас на руках (не
больше одного). **Пробел** — использовать. Все предметы, кроме «Защиты»,
срабатывают при касании мяча вашей кареткой:

- **Горящий мяч** — каретка горит 3 сек; удар поджигает мяч (+50% скорости).
- **Ослепление** — вспышка ослепляет всех соперников (до 3 сек, пока мяч не
  вернётся в их зону).
- **Кручёный** — мяч летит по дуге; траектория детерминированная, клиент
  предсказывает её локально.
- **Защита** — ворота непробиваемы 8 сек; после одного отражения щит ломается.
- **Заморозка** — морозит случайного соперника (−50% скорости каретки, 3 сек).
- **Обманка** — при ударе вылетает зеркальный мяч-фантом (пропадает за зоной).
- **Липучка** — мяч липнет к поверхностям на 0.6 сек (активное окно 6 сек).
- **Связывание** — верёвка привязывает мяч к каретке соперника; после 3
  отскоков связка рвётся.
- **Режим тряски** — «землетрясение» у всех, кроме использовавшего (6 сек).

## REST API

- `POST /create-room` — тело: `{ "maxPlayers": 4, "livesCount": 3, "ballAccel": true, "addBallTime": 15 }` → `{ "roomID": "..." }`
- `GET /rooms` — список активных комнат.

## WebSocket

- URL: `/ws?roomID=X&playerName=Y`
- Клиент → сервер:
  - `{ "action": "move", "dir": 1, "seq": 7 }` — `1`/`-1`/`0` (движение по грани) и номер ввода
  - `{ "action": "start" }` — запуск/рестарт создателем
  - `{ "action": "ping", "c": <clientTime> }` — замер задержки
- Сервер → клиент: `welcome`, `snapshot` (64 Гц), `pong`, `error`.

Снапшот содержит `t`, `state`, `you`, геометрию (`sides`, `radius`, `chamfer`,
`paddleHalf`, `paddleSpeed`, `ballRadius`, `ballSpeed`, `respawnIn`), массив `balls`
(`x,y,vx,vy`) и массив `players` (`id,name,index,angle,lives,isAlive,isHost,lastSeq`).
